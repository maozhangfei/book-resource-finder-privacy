这本书，哪里有 · 隐私政策

适用版本：1.1.0　更新日期：2026-10-14

本插件是独立的图书资源查询工具，在豆瓣图书详情页查询微信读书电子版和用户选择城市的公共图书馆馆藏或网借库存。与上述平台无隶属或官方合作关系。

读取和使用哪些信息

仅在豆瓣图书详情页提取书名、作者、ISBN、出版社和译者等书目元数据，用于查询和版本匹配。不读取豆瓣账号、评分、评论、其他网站内容或其他页面浏览历史，不进行广告、行为分析或用户画像，不读取定位、不按 IP 自动选择城市。

信息发送到哪里

配置个人 API Key 后，微信读书官方接口 i.weread.qq.com 会收到书名及来源图书 ID；Key 仅随请求发送给该官方接口。仅启用且获授权的图书馆来源收到 ISBN、书名和查询需要的来源记录 ID：

  • 北京·阅享京彩：apps.jiatu.cloud。
  • 上海·上海享借：xj.library.sh.cn。
  • 深圳·公共图书馆馆藏：www.szlib.org.cn。
  • 广州·快递书库：opac.gzlib.org.cn。
  • 杭州·公共图书馆馆藏：my1.zjhzlib.cn。
  • 成都·公共图书馆馆藏：opac.cdclib.cn。

不发送读者证、豆瓣账号或完整豆瓣页面地址。来源接口可能返回额外字段，插件仅保留查询需要的书目、馆名、公共馆藏地点和状态，不保存或展示其他读者信息。联网服务通常可看到 IP 地址等连接信息，其处理方式由对应服务决定。

无自建查询服务器，不接收用户书目、Key 或查询记录，不使用统计服务，不出售数据或用于广告。

本地存储与删除

Key 和城市设置保存在当前 Chrome 资料的插件本地存储中，不使用 Chrome 同步，Key 不向内容脚本提供读取权限。本地存储不是加密保险箱；请保护电脑和浏览器资料。可在设置页删除 Key；卸载插件会删除对应插件存储。

查询结果仅在浏览器会话存储中保存，上限 100 项，不包含 Key。微信读书匹配结果最长缓存 6 小时、未找到最长 15 分钟、其他状态最长 30 秒；图书馆结果最长缓存 1 分钟。可清除缓存；变更 Key、图书馆开关或城市选择会使相应来源的缓存失效。为同步设置到已打开的豆瓣图书页，会话中暂存最多 100 个对应标签页 ID，不存储页面地址或其他标签页内容。

用户选择与权限

新安装用户的图书馆查询默认关闭；从未设置城市的旧版升级时保留北京查询，已有设置予以保留。可关闭总开关或取消某个城市，停止相应查询并取消在途请求。首次勾选部分图书馆时，Chrome 可能申请对应网站的访问权限；此授权仅用于查询所选图书馆的馆藏和库存信息。授权成功后自动保存并启用，拒绝时保持原设置。关闭总开关会保留城市选择；重新开启时检查权限。城市选择与用户所在地无关，不获取地理位置。

不配置 Key 仍可开启图书馆查询。插件不登录图书馆，不代为借阅、预约或下单，不读取微信读书书架、笔记或阅读记录。馆藏在馆状态不保证可快递借阅；个人资格、配送和预约以官方平台为准。

政策更新和联系

后续改变数据用途或增加来源时同步更新本政策与商店说明。可通过 Chrome 应用商店详情页提供的开发者联系方式提出疑问。我们不持有服务器端用户数据，本地 Key 与缓存可直接在设置页删除。
