这本书，哪里有 · 隐私政策

适用版本：1.0.0　更新日期：2026-10-11

本插件是独立的图书资源查询工具，在豆瓣图书详情页查询微信读书电子版和阅享京彩馆藏，并提供 Anna’s Archive 搜索入口。与上述平台无隶属或官方合作关系。

读取和使用哪些信息

插件仅在豆瓣图书详情页提取书名、作者、ISBN、出版社和译者等书目元数据，用于查询和版本匹配。不会读取豆瓣账号、评分、评论、其他网站内容或其他页面的浏览历史，不进行广告、行为分析或用户画像。

信息发送到哪里

  • 配置个人 API Key 后，打开图书详情页会将书名发送到微信读书官方接口 i.weread.qq.com，查询相关书籍详情时还会发送来源返回的图书 ID。Key 仅随请求发送给该官方接口。
  • 阅享京彩查询会将 ISBN 或书名发送到公开书目接口 apps.jiatu.cloud；查询馆藏详情时发送对应记录 ID。不发送读者证、豆瓣账号或完整豆瓣页面地址。
  • Anna’s Archive 不会自动收到请求。只有点击搜索链接后，浏览器才打开来源网站并发送搜索词（ISBN，或缺少 ISBN 时使用书名和作者）。来源网站可能按自身政策处理 IP 地址、浏览器信息及其站点 Cookie。

联网服务通常能够看到访问者 IP 地址等连接信息，其保存和处理方式由对应服务自行决定。我们没有自建查询服务器，不接收用户书目、Key 或查询记录，不使用统计服务，不出售或将用户数据用于广告。

本地存储与删除

微信读书 Key 保存在当前 Chrome 资料的插件本地存储中，不使用 Chrome 同步，不向豆瓣页面提供读取权限。它不是加密保险箱；请保护电脑和浏览器资料，不分享个人 Key。设置页可以删除 Key；卸载插件会删除对应插件存储。

查询结果只保存在浏览器会话存储中，上限 50 项。微信读书匹配结果最长缓存 6 小时，阅享京彩匹配结果最长 1 分钟，未找到结果最长 15 分钟，其他状态最长 30 秒。缓存不包含 Key；可以在设置页清除。修改或删除 Key 会使原有缓存失效。

用户选择

不配置 Key 仍可使用阅享京彩和 Anna 搜索入口。关闭豆瓣图书页或禁用插件即可停止自动查询。插件不登录图书馆、不代为借阅或预约、不读取微信读书书架、笔记或阅读记录，也不直接下载电子书。

政策更新和联系

如后续版本改变数据用途或增加来源，我们会同步更新本政策和相关说明。疑问或删除请求可通过 Chrome 应用商店详情页提供的开发者联系方式提出。由于我们不持有服务器端用户数据，本地 Key 和缓存可直接在设置页删除。
